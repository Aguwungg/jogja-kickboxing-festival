# ONE Championship — feature analysis

**Observed URLs:** `https://www.onefc.com/`; `https://www.onefc.com/events/one-friday-fights-176/`.

## Homepage and event page
ONE uses a layered navigation model covering events, tickets, athletes, reading, watch, shop, about and languages. The homepage combines top stories, a next-event block, featured tags, latest stories, videos and conversion banners. The event page exposes date/time, venue, watch and ticket CTAs, countdown, past-events link and synopsis.

## Strengths
- Scalable content ecosystem for a growing combat brand.
- Strong conversion pairing: watch now and buy tickets.
- Event pages explain context before the full card is announced.
- Multilingual path is visible and intentional.

## Weaknesses / adaptation risk
- Large menu and content volume may be excessive for JKBF’s first festival edition.
- Generic blue hyperlink styling appeared in the rendered session, reducing art direction.

## JKBF adaptation
Use the event metadata block, watch/ticket pairing, and optional “latest stories” architecture. Keep navigation compact and Indonesian-first. Priority P1, complexity Medium.
