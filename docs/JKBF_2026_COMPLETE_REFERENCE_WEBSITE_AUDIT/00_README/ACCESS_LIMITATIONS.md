# Access limitations

1. **Previous conversation “JKF”:** unavailable as a readable conversation in this context.
2. **Persistent screenshots:** real screenshots were captured and inspected in the Cloud Browser, but the available API did not expose a file-writing/export operation. No artificial screenshots were added.
3. **Mobile viewport:** the browser session exposed a desktop viewport and did not expose a supported resize/emulation control. Mobile screenshot coverage is marked `NOT_CAPTURED`.
4. **BYON Events:** direct navigation redirected to `/login/` with a `redirect_to` parameter; public event detail pages were not available without authentication.
5. **Sónar programme routes:** `/en/programme` and `/en/programme/sonar-by-night` returned a client-side application error during direct inspection.
6. **Gymshark collection routes tested:** `/collections/new-in` and `/collections/lift` returned 404 in the live session; homepage merchandising patterns were inspected successfully.
