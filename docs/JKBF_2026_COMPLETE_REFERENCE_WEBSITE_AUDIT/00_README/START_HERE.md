# JKBF 2026 — Complete Reference Website Audit

This archive contains the public-site audit, feature benchmarking, JKBF page mapping, and evidence ledger produced on 21 October 2026.

## Scope

The work covered the current public JKBF site and six requested reference sites: BYON Combat, GLORY Kickboxing, UFC, ONE Championship, Sónar, and Gymshark. Observations are separated into directly observed browser evidence, inferred recommendations, and unverified items.

## Important evidence note

The Cloud Browser displayed real screenshots during the research session. In this execution environment, the browser screenshot API exposes image bytes for visual inspection but does not expose a persistent local export path. Consequently, screenshot files could not be safely written into the ZIP. The archive includes a screenshot capture ledger, URLs, viewport status, and explicit `NOT_CAPTURED` markers rather than fabricated or reconstructed images.
