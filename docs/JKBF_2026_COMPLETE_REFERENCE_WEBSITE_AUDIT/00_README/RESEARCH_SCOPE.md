# Research scope and method

- Date: 21 October 2026, Asia/Jakarta.
- Browser: Cloud Browser, desktop viewport rendered by the session.
- Method: direct navigation, accessibility-tree inspection, visual screenshot inspection, and read-only interaction where public and non-consequential.
- No purchases, payments, registrations, logins, account changes, or administrative areas were performed.
- Cookie banners were dismissed only where needed to inspect the public page.
- Mobile viewport resizing and persistent screenshot export were unavailable through the exposed browser API; mobile findings are therefore marked as unverified unless the site exposed mobile-specific navigation in the DOM.
