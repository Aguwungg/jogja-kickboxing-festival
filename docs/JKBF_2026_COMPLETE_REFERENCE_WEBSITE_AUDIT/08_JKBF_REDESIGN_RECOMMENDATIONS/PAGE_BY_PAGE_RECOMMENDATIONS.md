# Page-by-page recommendation matrix

## Homepage
- **Reference:** BYON + GLORY + Sónar
- **Feature:** Campaign hero, next event, three-pillar narrative, single ticket CTA
- **Retain:** Retain countdown and event facts
- **Do not copy:** Avoid poster copy and excessive red
- **Technical preservation:** Preserve configurable countdown and existing public routes
- **Priority:** P0

## Championship
- **Reference:** GLORY + UFC
- **Feature:** Division overview, title context, fight-card hierarchy
- **Retain:** Retain rules and divisions
- **Do not copy:** Avoid odds and unnecessary card tiers
- **Technical preservation:** Preserve championship data/API
- **Priority:** P0

## Fighters
- **Reference:** UFC + ONE + GLORY
- **Feature:** Directory filters, linked profiles, division metadata
- **Retain:** Retain athlete names and categories
- **Do not copy:** Avoid generic avatar cards
- **Technical preservation:** Preserve fighter data model
- **Priority:** P1

## Fighter Details
- **Reference:** UFC/ONE
- **Feature:** Profile hero, record/stat blocks, related bouts
- **Retain:** Retain factual profile content
- **Do not copy:** Avoid inventing statistics
- **Technical preservation:** Preserve profile endpoint
- **Priority:** P1

## Bracket
- **Reference:** GLORY
- **Feature:** Round tabs or progressive tournament tree
- **Retain:** Retain 8-man structure
- **Do not copy:** Avoid unreadable desktop-only tree
- **Technical preservation:** Preserve bracket logic
- **Priority:** P0

## Lineup
- **Reference:** Sónar
- **Feature:** Day/genre/venue storytelling and artist modules
- **Retain:** Retain music pillar
- **Do not copy:** Avoid copying Sónar visuals
- **Technical preservation:** Preserve lineup data
- **Priority:** P1

## Schedule
- **Reference:** Sónar + JKBF current
- **Feature:** Day selector + category filters + time/location
- **Retain:** Retain current filters and agenda copy
- **Do not copy:** Avoid long undifferentiated list
- **Technical preservation:** Preserve schedule data
- **Priority:** P0

## Venue
- **Reference:** Sónar practical info
- **Feature:** Directions, access, zones, map and visitor notes
- **Retain:** Retain GOR UNY facts
- **Do not copy:** Avoid decorative map without utility
- **Technical preservation:** Preserve venue content
- **Priority:** P1

## Tickets
- **Reference:** UFC/ONE/GLORY
- **Feature:** Package hierarchy, availability, event proof
- **Retain:** Retain ticket categories and payment flow
- **Do not copy:** Avoid multiple dominant red CTAs
- **Technical preservation:** Preserve payment verification
- **Priority:** P0

## Merchandise

- **Feature:** Collection/product cards, trust/footer cues
- **Retain:** Retain product data and checkout

- **Technical preservation:** Preserve cart/payment logic
- **Priority:** P1

## FAQ/Contact/Privacy/Terms
- **Reference:** UFC/GLORY/Sónar
- **Feature:** Compact utility IA and accessible accordions
- **Retain:** Retain legal copy
