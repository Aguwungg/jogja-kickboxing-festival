# JKBF design preference profile

The inaccessible “JKF” conversation prevents a full decision-history reconstruction. Based on the supplied brief, current site and project context, the practical profile is:

- Premium combat-sports intensity with contemporary festival culture.
- Black #0B0B0B, red #D91F2C and warm ivory #F4F0E8 used with restraint.
- Real photography and credible event information over synthetic or AI-looking visuals.
- Strong editorial art direction, controlled asymmetry and purposeful whitespace.
- Mobile-first navigation and conversion paths.
- Distinctive Jogja identity without tourism clichés.
- Readable fighter, championship, schedule and ticket data.
- Expressive typography paired with disciplined metadata hierarchy.
- A website that feels like a major event while remaining realistic for the existing technical architecture.
