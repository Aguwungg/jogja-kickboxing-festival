# BYON Combat — feature analysis

**Observed URLs:** `https://byoncombat.com/`; direct `/events` navigation redirected to login.

## Homepage
BYON presents a black, high-contrast combat brand with an orange active nav state and a large fighter-vs-fighter promotional hero. The visual language is entertainment-first: opponent names, discipline, date/venue, countdown blocks, and paired ticket/PPV CTAs appear early. The homepage then moves into past fight results, an about statement, achievement metrics, and footer ecosystem.

## Strengths
- Immediate fight proposition with named opponents and event context.
- Clear separation of ticket and PPV actions.
- Fighter results expose method, round and time, creating credibility.
- Simple global nav: Home, Fighters, Events, Rankings, Merchandise.

## Weaknesses / adaptation risk
- Directly copying blue/orange event-poster energy would make JKBF look derivative.
- Public Events route required login in this session, so authenticated event behavior remains unverified.

## JKBF adaptation
Use the energy principle for the homepage hero and a compact “next fight” or “featured division” module. Translate the orange accent logic into JKBF red and warm ivory, use Jogja photography, and preserve a single dominant ticket CTA. Priority P1, complexity Medium.
