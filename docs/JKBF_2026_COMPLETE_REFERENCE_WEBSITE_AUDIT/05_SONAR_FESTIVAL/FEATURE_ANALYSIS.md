# Sónar Festival — feature analysis

**Observed URL:** `https://sonar.es/en`.

## Homepage
Sónar presents a calm, editorial festival identity with utility navigation for Sónar around the world, Sónar Week, practical information, news, about and language. The second navigation layer exposes the current edition, galleries, SonarMix, Sónar+D and partners. The page includes a feature carousel with slide indicators, editorial copy and a Watch now action, plus newsletter signup, sponsor logos, app links and legal navigation.

## Programme limitation
Direct inspection of `/en/programme` and `/en/programme/sonar-by-night` returned a client-side application error in this session, so timetable interaction is not directly verified.

## Strengths
- Strong separation between event identity, practical information, editorial content and partner ecosystem.
- Restrained typography and whitespace let the festival identity breathe.
- Carousel indicators and utility navigation provide orientation without overloading the hero.

## JKBF adaptation
Use the information architecture for a three-day schedule: day selector, activity category filters, venue/practical information, galleries and sponsor hierarchy. Do not borrow Sónar’s art direction or typographic personality. Priority P0 for schedule IA, complexity Medium.
