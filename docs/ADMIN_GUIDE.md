# Admin Guide

## Overview
The Admin Command Center (`/admin`) is the central control panel for the JKB 2026 platform. It allows authorized personnel to manage content, users, e-commerce, and competition data without needing to modify source code.

## Roles & Permissions
- **SUPER_ADMIN**: Full access to all systems, users, and settings.
- **CONTENT_ADMIN**: Manage homepage content, announcements, FAQs, and general CMS pages.
- **EVENT_MANAGER**: Manage schedules, artists, and event information.
- **COMPETITION_OPERATOR**: Manage fighters, matches, and brackets.
- **CREATOR_MANAGER**: Review and approve creator content submissions and barcodes.
- **MERCH_MANAGER**: Manage products, inventory, and orders.
- **FINANCE_VIEWER**: Read-only access to sales and PPV reporting.

## Publishing Workflow
- Content can be saved as Draft, Scheduled, or Published.
- Scheduled content is enforced on the backend.

## Security
- Always verify data changes.
- Ensure correct role assignment.
