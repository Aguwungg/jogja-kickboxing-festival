# JOGJA KICKBOXING FESTIVAL & REDY CHAMPIONSHIP 2

## OFFICIAL DIGITAL PLATFORM

The central digital hub for JKB 2026, featuring e-commerce, PPV, championship brackets, creator hub, and city pride voting.

### Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- PostgreSQL (Prisma)

### Local Development
1. Clone the repository.
2. Install dependencies: `npm install`
3. Copy `.env.example` to `.env` and configure your local database URL.
4. Run migrations: `npx prisma db push`
5. Start development server: `npm run dev`
